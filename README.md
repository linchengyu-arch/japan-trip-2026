## 發布 GitHub Pages
1. 開啟儲存庫 Settings → Pages。
2. 在 Build and deployment 的 Source 選 **Deploy from a branch**。
3. Branch 選 **main**，資料夾選 **/(root)**，按 Save。
4. 等待部署完成，打開上述網址。
